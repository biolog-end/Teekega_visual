# Визуализатор чатов Telegram

[English](README.md) · **Русский**

Статический браузерный визуализатор JSON-экспортов чатов Telegram.
Загрузите файл, выберите режим - всё парсится и отрисовывается локально, ничего не уходит со страницы.

## Режимы

| Режим | Описание |
| --- | --- |
| **Bar Chart Race** | Гонка самых частых слов на скользящем окне |
| **Line Chart Race** | Плавные линии популярности слов с финальным рейтингом по пику |
| **Тепловая карта** | Календарь активности в стиле GitHub |
| **Суточный ритм** | Punch Card: час × день недели |
| **Баланс сил** | Кто больше говорит, кто инициатор, время ответа, уникальный лексикон, золотой день |
| **Ngram трекер** | Частота любого слова во времени |
| **Пузырьковая хроника** | Scatter-карта дней: сообщения / длина / тип контента |
| **Т9 чата** | Генератор фраз на марковских цепях под каждого собеседника |
| **Открытые слова** | «Word Pokédex» - какие частотные слова русского языка уже встречались в чате, а какие ещё нет |

## Как пользоваться

1. Экспортируйте чат Telegram в JSON (в десктоп-клиенте: меню чата → *Экспорт истории чата* → JSON).
2. Откройте [`index.html`](index.html) в современном браузере или поднимите папку локальным сервером:
   ```
   python -m http.server 8000
   ```
3. Перетащите `result.json` в зону загрузки.

Парсинг идёт в Web Worker, поэтому даже экспорты в сотни мегабайт не подвешивают интерфейс.

## Структура

```
index.html         точка входа
app.js             диспетчер модулей
upload.js          загрузка файла + парсер в Web Worker
styles.css         тема и все стили визуализаций
css/markov.css     стили режима «Т9»
{module}.js        отдельный файл на каждую визуализацию
```
